# Observation logs

One file per observation session, named `YYYY-MM-DD-<area>-<initials>.md`, using
[`docs/legal/templates/observation-log.md`](../../docs/legal/templates/observation-log.md).

No screenshots, no copied text, no file or binary inspection. See the [clean-room protocol](../../docs/legal/clean-room.md) §5.1.
